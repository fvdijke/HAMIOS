# HAMIOS v5.8.1 — Themes

**Release Date:** September 28, 2026
**Build:** PyInstaller 6.x | Python 3.10

---

## 🎨 Themes (Settings → Layout)

- **Night** — the familiar dark look (default, unchanged)
- **Day** — a light theme with warm off-white panels; status colours are darkened so they stay readable on a light background
- **High readability** — near-black background, brighter text, clearly readable dimmed text, stronger borders and 15 % larger text

## 🖌 Theme designer

Build your own theme:
- 19 colours in four groups: backgrounds, text, accent and status colours — via a colour picker or a hex code
- Text size from ×0.8 to ×1.6
- Start from Night, Day or High readability
- Live preview of a HAMIOS panel, with a contrast check that warns when text becomes hard to read

A theme is applied at start-up. When you pick a different theme, a **Restart now** button appears: it saves your layout and settings and restarts HAMIOS.

The world map keeps its own colours in every theme, so night shading, grey line and aurora stay correct.
